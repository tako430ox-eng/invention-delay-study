# 30件の再判定: 目的と予想(再判定を見る前に固定)
目的(この結果で答えがどう変わるか): 30件の分類が判定者に依存するかを知る。一致が低ければ、「前提が深いが最多」「構想の壁は1割強」という結論を取り下げる。
方法: 事情を知らない別の判定者(新しい文脈の別のモデル Sonnet)に、同じ基準と、コードを消した同じ資料の要旨(blind_recode/)だけを渡す。
限界: 資料の要旨はこちらが選んで書いたもので、資料集めの段階の偏りは確かめられない。判定者も同じ会社のAI。

## 予想
1. 30件の一致率は 50〜75%。75%を超えれば分類は頑健、50%未満なら現在の集計は判定者の癖とみなし取り下げる。
2. 不一致の半分以上は R・U・N の間で起きる(境界があいまいなため)。外れたら、あいまいなのは別の箇所と考え直す。
3. C と判定した3件(熱風送風、缶詰、蓄音機)のうち、2件以上が再判定でも C。1件以下なら「構想の壁」の型は判定者依存とみなし、次の深掘りの対象を選び直す。
