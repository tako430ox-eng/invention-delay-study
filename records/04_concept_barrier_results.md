# 「構想の壁」3件の厳しい確認: 結果(基準と予想は 03、SHA-256 2a49e163…)
資料: Wikipedia(James Beaumont Neilson、Hot blast、Phonautograph、Phonograph、Canning、Nicolas Appert)、Grace's Guide(Neilson の追悼記事)。いずれも二次資料。2026-11-16 閲覧。

## 1. 先行研究(作業の前の確認)
- Tabarrok(Marginal Revolution、2010)が「時代に遅れたアイデア」(もっと早く見つかり得たのに見つからなかったもの)という区分を提案。例は実験経済学、無作為化臨床試験など。原因の分類は無く、「どんな種類のアイデアが遅れやすいのか」と問うだけ。
- Tabarrok(2026-05)が Potter の一覧を引き、「役に立つ技術の多くは可能になると速く発明される」「まれに本当にもっと早くできた」と書き、缶詰とジャカード織機を「かなり遅れた」例に挙げ、「パターンはあるか?」で終わる。
- Crawford の「なぜこんなに時間がかかったか」の事例集(自転車、飛び杼、脱穀機など)。原因の比較はあるが、件数での分類は無い。
- 3行のまとめ: 「時代に遅れたアイデア」という問いと事例集は既にある。原因の型を件数で分けた分析は、見つけた範囲では無い。Tabarrok 自身が「パターンはあるか」を未解決の問いとして残している。

## 3. 予想の採点
1. 3件中2件以上が「確認」→ **外れ**(確認0件、保留3件)。事前の決まりにより、「構想の壁を次の重心にする」という提案を取り下げる。
2. 熱風送風は4条件すべて → 外れ(K1・K2 が資料不足)。
3. 蓄音機は K2 が最も弱い → 当たり。
4. 缶詰で近い試みが見つかる → 当たり(1772年のオランダ海軍)。

## 4. 分かったこと
- 3件とも、反証されたのではなく、二次資料では「部品と動機が20年以上前からあった」を年付きで示せなかった。厳しい条件にすると、ウェブの二次資料では決着しない。
- 3件は同じ型ではなかった。熱風送風は「誤った通念」、蓄音機は「再生という目的そのものが立っていなかった」(問題の認識の壁に近い)、缶詰は「家庭の方法の工業化」で、構想の壁かどうか自体が怪しい。「構想の壁」は1つの型ではなく、少なくとも2つに分かれる。
- K4 は3件とも満たした。着想が出た後の広がりは速い。これは「機が熟せば速い」とも「着想が律速だった」とも読め、K4 だけでは区別できない。
