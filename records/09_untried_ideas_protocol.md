# 試行: 「書かれているのに試されていない着想」は、その後どうなったか(調査前に固定、2026-11-17)
目的(答えがどう変わるか): 今の世界で「作れるのに作られていない物」を探す入口として、論文に「まだ試されていない」と明記された着想が使えるかを確かめる。多くがすぐ試されていれば、この入口から残り物は見つからない(人類はここでも速い)。多くが残っていれば、探し方の候補になる。

## 先行研究(3行)
- 自分たちの段階2(2026-11-10): 長く引用されなかった論文が後に注目される割合は約0.2%で、事前の予測は難しかった。
- 医療の「逆転」研究(Prasad ら 2013、Mayo Clin Proc): NEJM 2001〜10年に既存の医療行為を検証した363本のうち146本(40%)で無効と判明。もっともらしさや観察データで、確かめずに広まった例が多い。こちらの問いはその逆(良さそうなのに試されない)。
- 文献から未発見のつながりを探す研究(Swanson 1986 以降)はあるが、論文の中の「未検証」と明記された着想を追跡した研究は、見つけた範囲では無い。

## 方法
- 母集団: OpenAlex で 2010〜2012年に出た、物理科学の領域(工学を含む)の論文のうち、題名か要旨に "has not yet been tested" "has never been tested" "has not yet been attempted" "has never been attempted" "has not been tried" のいずれかを含むもの(約119件)。
- 乱数(seed 20261117)で並べ、上から読んで、未検証とされている対象が「作る物・方法・応用」であるものだけを採用し、20件に達したら止める(理論や仮説の検証は除く)。
- 各件について、2025年までにその着想が試されたかを、OpenAlex とウェブの検索で1件あたり3回まで調べる。
- 分類: D 試された(論文・製品あり)/ X 試されて駄目だった / S 見つからず(試されていないか、見つけられない)。

## 予想(外れたら何を捨てるか)
1. D+X が 20件中 12件以上。外れて S が9件以上なら、「書かれた未検証の着想」は今も残り物を含む入口として有望とみなし、規模を広げる。
2. D の多くは、元の論文の著者自身か同じ研究室が試している。外れれば、着想が他人に拾われて試されることが多いと考え直す。
3. S のうち、理由が読み取れるものの多くは「費用」か「需要が小さい」。
限界: 判定は私1人。「見つからず」は「無い」の証明ではない。
