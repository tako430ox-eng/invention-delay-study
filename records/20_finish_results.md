# 20 出来ることを出し尽くした結果 2026-11-19

計画と予想は 19_finish_protocol.md(先に記録・ハッシュ済み)。作業の記録は、作業者ごとの報告を写したメモ(scratchpad/p19/notes.md)にある。主な数字はこの文書に写した。

## 0. 結論(先に)
1. **18の計算は、別の作業者が別の方法で出した値と一致した**(差は最大で約9%、ほとんどは1%以内)。3つの数字が「条件次第で5〜16倍変わる」という結果は確かになった。
2. **設計の数字の台帳を10個に広げた。** 10個すべてが、言い方に書かれない条件(厚さ、面の間隔、立ち上がり時間、周波数)に依存していた。比べた測定や計算があったのは6個で、そのうち4個は「決まりの言う通りにはならない、または条件付き」という結果だった。18で見た「条件を失った数字」は、3つに限った話ではなかった。
3. **16の結論3(今は書かれた着想がすぐ試される)は誤りだったので訂正する。** 他の人に向けた「〜に応用できるかもしれない」という提案は、今(2010〜12年)も昔(1965〜85年)も、10年以内に実際に示されたのは2割ほどだった。時代による違いは見えなかった。10で「20件中19件」と出たのは、「まだ試されていない」と書く人の多くが同じ論文で自分で試していた、という拾い方の偏りによるものだった。
4. 読めなかった資料のうち、Hubing 2003 は読めた。3:1 は、見つけた範囲では TI SZZA009(1999年)が最も古く、その前身の TI の文書(1996年)には無かった。

## 1. a 独立の再計算(予想: 20%以内で一致 → 当たり)
作業者は私の結果を見ずに、2次元のモーメント法と3次元の部分インダクタンスで計算した。照合では Hammerstad-Jensen の式と0.16%以内、厳密解のある問題と0.0014%以内で一致した。
| 量 | 私(18) | 独立 |
|---|---|---|
| 3:1 の幅25 mm と0.25 mm の比(2次元) | 5.6倍 | 5.55倍 |
| 同(3次元、端の効果を含む) | 8.1倍 | 8.5倍 |
| はみ出し6.35 mm の倍率(1.6 mm 厚) | 1.016 | 1.0161 |
| はみ出し1 mm / 2 mm | 1.084 / 1.053 | 1.0852 / 1.0538 |
| 3W の漏話の比(厚さ/線幅 2 と 0.25) | 15.7倍 | 16.75倍 |
| 3W の漏話(1.6 mm 厚、線幅0.25 mm) | 0.179 | 0.177 |
注: 漏話の係数には定義の流儀が2つある。今回は両者とも同じ流儀を使った。もう一方の流儀では値がやや大きくなるが、結論は変わらない。

## 2. b 設計の数字の台帳(予想: 半数以上が条件に依存し、その条件が書かれない → 当たり、10/10)
| 数字 | 依存する条件(普通は書かれない) | 比べた検証 | 結果 |
|---|---|---|---|
| 20H(電源面を引っ込める) | 面の間隔、周波数、層の構成 | 実測: Shim & Hubing 2001 | 決まりに従うと放射は「わずかに大きい」。1999年に SI-List で「数字は見つからない」と書かれ、出どころは Mike King とされる |
| ビアの並べ方 λ/20 | 周波数、比誘電率、ビアの間隔 | 計算: Tischler ほか 2003 | 簡単な式の上限(77 GHz)より実際の限界(約60 GHz)が低い |
| デカップリングを「X mm 以内」 | 面の間隔 | 実測: Shi ほか 1996 | 面の間隔が10 mil 以下なら、置く場所によらない。場所が効くのは0.5 mm より離れた面だけ(CVEL) |
| 終端は立ち上がり時間の長さの1/6 | 立ち上がり時間 | 無し(導出のみ) | Johnson 1999 の個人の目安。人により1/10〜1/3 |
| 90°の角を避ける | 立ち上がり時間、線幅 | 実測: Brooks 1998 | 17 ps の TDR で「測れる反射は無い」。放射の差も測定誤差の範囲 |
| クロックの配線は N インチ以下 | 高調波の周波数 | 一部の実測: In Compliance 2024 | 短い方が27 MHz で約7.5 dB 良いが、他の帯ではほぼ同じ。N を試したものは無い |
| 3W | 厚さ h | 計算(LearnEMC 2025、18) | h の3倍が正しい形 |
| 1/4インチのはみ出し | 厚さ h | 見つからず(18で計算) | 1.6 mm 厚なら十分、薄い基板には過剰 |
| 3:1 | 幅、厚さ | 見つからず(18で計算) | 幅の広い配線でだけ筋が通る |
| デカップリングごとにビア | 面までの深さ | 実測: Magnusson 2014 | 近づけると効く(0.63→0.44 nH)。ただし表か裏かで2倍変わり、その方が大きい |
- 【事実】比べた検証があるのは6個(実測5、計算1)。そのうち4個(20H、ビア、デカップリングの距離、90°)は、決まりの言う通りにはならないか、条件付きだった。
- 【推論】経験則の数字は、ある条件での正しい値が、条件を書かれずに広まったものが多い。測ると、効かないか、条件次第になる。20H のように、出どころの人さえ「数字は無い」と認めていた例もある。
- 限界: 調べたのは作業者1人で、数字1つにつき検索2回まで。いくつかの論文は要旨しか読めていない。

## 3. c 昔と今の「応用できるかもしれない」(予想: 昔は今より20ポイント以上低い → 外れ)
| | 昔(1965〜85年) | 今(2010〜12年) |
|---|---|---|
| 10年以内に示された(D10) | 5/20(25%)。ただし今の側の基準で数え直すと2/20(10%)※ | 4/20(20%) |
| 10年より後に示された(D+) | 5/20(遅れは12〜31年) | 0/20(観察できる期間が13〜15年しかない) |
| 試されて駄目だった(X) | 0 | 0 |
| 見つからない(S) | 10/20 | 16/20 |
| 示した人 | 他の人が多い(10件中7件) | 4件中3件が同じグループ |
※ 昔の側の作業者は判定が甘かった(本人が但し書きを付けている)。うち2件は元の論文より前の実施で、1件は弱い証拠だった。今の側の作業者は、こうした場合を「見つからない」としていた。
- 【事実】10年以内に示された割合は、どちらの時代でも1〜2割だった。予想の「昔の方が20ポイント以上低い」は外れた。決めておいた通り、「今は書かれた着想がすぐ試される」(10)は、時代の違いではなく拾い方によるものとみなして取り下げる。
- 【事実】昔の側では、40年かけて半分(10/20)が示された。示されるまでに10年より長くかかったものも、同じくらいあった。
- 【探索的。先に予想していない】示された提案の元の論文は、示されていない提案の論文より多く引用されていた。中央値は昔が15.5回と8回、今が58回と2.5回。ただし、作業者は引用している論文をたどって探したので、引用の多い論文ほど見つけやすい。この差の一部は、探し方によるものである。
- 【推論】論文に書かれた「応用できるかもしれない」の多くは、誰にも試されないまま残る。ただし、多くは注目されない小さな提案で、価値が高いのに放置されたとは言えない。これは05で挙げた人口の観点(関わる人が多い所ほど試される)と同じ向きだが、検証はしていない。
- 限界: 時代ごとに別の作業者が判定した(判定の癖が混ざる)。昔の文献はデータベースに少ない。各時代20件ずつと少ない。

## 4. d 読めなかった資料
- Hubing 2003(注釈付きの一覧)は、CORE の公開版を読めた。2層基板の決まり(格子、3:1、1/4インチ)、3W、20H は扱っていなかった。接地面の切れ目については「指針に従うためだけに切ってはならない」とある。この論文自体には測定は無い。
- Hu & See 2005(電子実装の会議 EPTC 2005): 要旨だけ読めた。分割接地の指針には「厳密な分析がほとんど無い」とある。結果は読めなかった(有料)。同じ研究室の学生の報告(2013年)には、分割で5 GHz の遮断が最大20 dB 良くなる一方、遠方への放射は増えたとある(学生の報告なので弱い)。
- 華岡: Wikipedia には「鎖国で1854年まで知られなかった」「印刷された本が無く、写本だけだった」とある。華佗の麻沸散は、存在そのものに異論がある(Zhao 2018)。
- 3:1 の出どころ: TI SZZA009(1999年)より古いものは見つからなかった。TI の前身の文書(SDYA011、1996年)には無い。Motorola AN1259(1995年)は「短く太く」と書くだけで、比は書いていない。Freescale AN2536 と Montrose の本は読めていない。
