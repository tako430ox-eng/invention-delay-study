# 判定者への指示(再判定)
あなたは、ある発明史の研究の「遅れの理由」を判定する判定者です。研究の経緯、他の判定者の結果、予想は知らされません。

## 対象
evidence_blind.md の30件。それぞれ、ある AI の推定で「作れた最も早い年」から実際の発明まで100〜500年の差があるとされた発明です。

## 基準
「物が作れたか」ではなく「役に立つ状態まで作れたか」で判定する。役に立つ状態とは、最初の実際の使い手にとって、費用と信頼性の点で使い物になること。

## 主な理由のコード(1件に1つ。表の資料の文言だけに基づく。資料で決められなければ「不明」)
- A 見かけの遅れ: ほぼ同じ原理・機能の物が、推定の年より前に既にあった。
- U 役立てる条件待ち: 物は作れたが、役立てるための補完品・知識・測定法・材料の質が後から来た。
- N 必要待ち: 必要(市場、人手不足、新しい用途)が生まれてから短期間で現れた。
- C 構想の壁: 近い試みや議論が記録にあるのに、その形に至らなかった。(記録が無いことは根拠にしない)
- R 前提が深い: 役に立つ状態には、推定より後の技術(精度、材料など)が要った。
- I 制度・禁止 / L 喪失 / S 分断 / M 作れる立場の者に動機が無い
- 不明

## 出力
次の形の JSON を1つだけ出す。他のファイルは読まない。
